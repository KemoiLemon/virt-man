# Virt-Man

Personal VM manager: Proxmox is too heavy, raw libvirt is too light. A Rust
**daemon** controls libvirt; a **web UI** (with user auth, RBAC, and a daemon
proxy) and a **Tauri desktop app** (standalone, same UI) sit on top.

## Components

| Part | Path | What it is |
|---|---|---|
| daemon | `daemon/` | Rust + axum; token-authenticated HTTPS API over libvirt (domains, networks, storage pools, volumes, lifecycle, native VNC console + virt-viewer handoff for SPICE) |
| web UI | `web/` | Vite + TS SPA, served by the Rust backend in `web/server/` (users, RBAC, API keys, daemon connections + TLS-pinned proxy) |
| client | `client/` | Tauri v2 desktop shell: embeds the web UI, runs the backend as a local sidecar, NVIDIA/WebKitGTK workarounds, frameless window |

## Install the daemon

```bash
cd daemon
sudo ./install.sh
```

This builds the daemon, installs it to `/usr/local/bin`, creates
`/etc/virt-man/{token,daemon.toml,tls/}`, generates a self-signed TLS cert
(SANs: localhost + hostname + host IPs, as an end-entity leaf so clients can
pin it), and enables `virt-man-daemon.service`. The daemon listens on
**`0.0.0.0:8443`** (HTTPS).

The token is at `/etc/virt-man/token`. When adding the daemon to the web UI or
app, paste that token and confirm the cert fingerprint.

## Install the web UI

```bash
cd web
sudo ./install.sh
```

Builds the SPA (`web/dist`) and the Rust backend (`virt-man-web`), installs
the binary to `/usr/local/bin` and the static assets to
`/usr/local/share/virt-man/dist`, creates `/var/lib/virt-man`, and enables
`virt-man-web.service`. The web UI serves **HTTPS on `0.0.0.0:8006`** with an
autogenerated cert. First visit opens the setup wizard (create the admin
user), then add a daemon under Datacenter.

## Install the desktop app

```bash
sudo ./client/install.sh
```

Builds the web UI + backend + Tauri shell and installs everything to
`/opt/virt-man/` (app, sidecar backend, static assets, icon) plus a
`.desktop` launcher. The app spawns the bundled backend as a local sidecar
(loopback HTTP on a free port) with its own data dir
(`~/.local/share/virt-man`), so it manages daemons independently.
"Connect to a webui" navigates the window to a remote web UI URL. The
frameless titlebar drags/maximises/minimises/closes via the app window
controls.

## Development

```bash
# web UI
cd web && pnpm install && pnpm dev                # Vite dev (proxies /api)
VIRT_MAN_WEB_LOOPBACK_HTTP=1 VIRT_MAN_WEB_PORT=8787 \
  cargo run --manifest-path web/server/Cargo.toml  # backend, loopback HTTP

# desktop app
cd client && pnpm install && pnpm tauri dev
```

## Notes

- Daemon token: read from `/etc/virt-man/token` (mode 0600).
- Web UI binds `0.0.0.0:8006` (HTTPS) by default; override with
  `VIRT_MAN_WEB_BIND` / `VIRT_MAN_WEB_PORT`.
- Certificates are pinned per daemon (not a CA), so existing daemons can be
  adopted by pasting their token and confirming the fingerprint.
